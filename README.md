# CyberGhana Academy

**Learn. Secure. Protect.**

CyberGhana Academy is a beginner-friendly educational website about cybersecurity awareness, online safety, and responsible security learning.

## Features
- Responsive layout for desktop and mobile
- Learning topic cards for network security, phishing, password safety, and ethical hacking
- Interactive online safety checklist with progress indicator
- Mobile navigation menu
- HTML, CSS, and JavaScript kept in separate files

## Project files
- `index.html` — page structure and content
- `style.css` — design and responsive layout
- `script.js` — navigation and checklist interactions

## Run locally
1. Extract the ZIP file.
2. Open the `CyberGhana-Academy` folder.
3. Double-click `index.html` to open it in a browser.

No installation or build tools are required. An internet connection is only needed for the optional Google Fonts import; the site still works without it.

## Publish with GitHub Pages
1. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then save.
5. Wait for deployment and open the published URL shown in Pages settings.

## Responsible-use notice
This project is for education and cybersecurity awareness. Only test systems you own or have explicit permission to assess. The site does not provide a certification or professional security advice.
